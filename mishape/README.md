# MiShape 0.2

MiShape 是一个在本机运行的 polygon 车辆造型工作台。它包含「模型塑形」与「参数生成」两套工作流：对已有车辆进行关键参数和粗控制笼形变，或从尺寸与构型参数生成车辆，再继续编辑、比较和批量探索。

本次交付提供可运行的软件、两辆真实 Porsche 素材、参数化生成器、组件操作、工程保存和几何导出。它面向概念造型与设计空间探索；尚未完成制造、公差、装配、碰撞、CFD 或 Class-A 曲面的生产认证。

## 启动

macOS 双击 `start.command`。也可以在项目目录运行：

```sh
bash mishape/start.sh
```

在浏览器打开 [http://127.0.0.1:8010](http://127.0.0.1:8010)。启动器优先使用父级项目或本目录的 `.venv`；没有可用环境时使用已安装的 Python 3.11+ 创建环境，并通过 `requirements.txt` 安装依赖。首次安装需要联网，已有依赖与素材后的日常使用在本机完成。浏览器需支持 WebGL2。

```sh
# 只检查目录和依赖，不启动服务、不安装依赖
bash mishape/start.sh --check
```

服务固定绑定 `127.0.0.1:8010`。保持启动终端开启；按 `Ctrl+C` 停止。若端口被其他程序占用，先在对应程序中释放端口。MiShape 不会停止或替换旧 AeroShape 服务。

## 开始一次设计

1. 在左侧选择 `911 930 Turbo` 或 `911 Carrera 4S`，或导入 OBJ、STL、PLY、GLB、MiShape JSON 工程。未知单位时输入已知车长，并确认源模型的车头和向上坐标轴。
2. 在「模型塑形」右侧分组滑块中修改参数。滑块是相对基准车的位移或角度增量；改变后自动更新三维结果与测量。
3. 打开右侧「控制点」。默认控制笼沿车头、车顶、车尾和截面宽度贴合车身；选择粗、标准、精细或自定义 XYZ 节点数与外扩距离，再点击「应用控制笼设置」。按住 `Shift` 拖动边界控制点，或输入 X/Y/Z 位移。默认启用左右对称及车轮刚性保护。
4. 使用前后、侧面、顶视和双视图比较；在组件列表或模型上选择组件，查看隔离与展开效果。
5. 保存 JSON 工程以保留基准模型与编辑配方；导出 OBJ、GLB 或 STL 交给下游工具。
6. 打开变体组合，选择采样参数、数量、种子和探索幅度，一次生成最多 50 个变体。组合提供缩略图、继续编辑入口和包含 OBJ/参数/质量记录的 ZIP。

「参数生成」支持溜背、三厢、旅行车、两厢与 SUV，提供 28 个连续尺寸/造型参数和后视镜、尾翼、前脸、扩散器选型。生成车辆可以转入「模型塑形」。70 个精细造型系数目前通过 Python/API 使用，界面没有对应滑块。

控制笼密度提供粗 `5×3×3`、标准 `9×3×4`、精细 `13×5×5`，最多 `17×7×7` 个绑定节点；仅显示和拾取边界点。单纯改变贴形笼密度不会改变参数滑块生成的形状。已有手动编辑会重采样到新笼，降密度可能损失局部细节，面板持续显示全模型最大/RMS 偏差，可直接撤销。笼设置与控制位移一起保存、批量生成及重放；旧工程仍按原来的方形 `7×3×4`、零外扩重放。

## 数据与重要区别

| 数据 | 当前作用 |
| --- | --- |
| 内置车辆 `viewport.json` | 工作台实际编辑、比较和导出的 polygon 显示网格 |
| `fullmesh.json.gz` | 完整求值网格档案，保留 polygon 与 UV，独立于显示 LOD |
| `original_mesh.json.gz` / `source.blend` | 原始控制多边形、材质/UV、对象及修饰器的保留档案 |
| MiShape 工程 JSON | 当前基准网格 + 参数 + 控制点 + 编辑选项，可重新导入重放 |
| `mishape/.state` | 本机模型缓存和批量产物；可通过 `MISHAPE_STATE` 改变位置 |

当前界面不会把 LOD 形变自动传回原始 Blender 文件或全精度档案。OBJ 导入保留原始多边形和组件（显示时确定性三角化），STL/PLY/GLB 使用三角面拓扑；内置素材和原生工程保留所携带的 polygon 索引。运行时显示材质基色、金属度和粗糙度；原始图像纹理在素材目录保留，界面暂不贴图。

两辆 Porsche 没有用户提供的真实尺寸标注，分别按约 4.30 m / 4.43 m 车长归一化。其毫米尺寸属于待校准估计；在「测量与校准」输入已知车长可直接校准当前形状并建立新基准，角度和轮轴位置也应结合关键点面板复核。

完整操作说明、17 个塑形参数定义、生成参数、接口和已知限制见 [交付与技术说明](docs/DELIVERY.md)。素材处理记录见 [素材说明](assets/README.md)。

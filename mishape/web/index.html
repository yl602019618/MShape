WORKING WITH MISHAPE

从参数到多边形

  1. 选择一辆车点击左侧 Porsche 素材，或导入自有模型。未知单位时按车长校准。
  2. 探索关键参数右侧滑块以原模型为基准；车长、玻璃、前后悬与姿态分组控制。
  3. 直接编辑控制点控制点面板可选择贴合车身、设置粗细或自定义分段。点击应用后，Shift + 拖动或输入精确位移；密度变化会迁移已有编辑，并可撤销。
  4. 比较与批量生成启用双视图；创建最多 50 个变体，下载 OBJ、参数与质量记录。
  5. 从零生成切换「参数生成」，输入整车尺寸和详细造型参数，再进入塑形微调。
MiShape 0.2 是可运行的多边形造型工作台。自动关键点和角度属于几何估计；当前质量检查覆盖有限数值、退化面与翻转等项目，不包含完整自交、装配、公差或可制造性验证。原素材的 UV/纹理副本保存在素材目录，工作室使用材质基色显示。
